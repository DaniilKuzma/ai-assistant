# Подсветка исправлений в GUI

В GUI-приложении есть функция визуального сравнения исходного текста и результата модели. Она помогает быстро увидеть, какие фрагменты модель изменила.

Основные файлы:

```text
app/main.py
app/text_highlighter.py
```

## Как пользоваться

1. Запусти GUI:

```bash
python app/main.py
```

2. Введи текст с ошибками в левое поле.
3. Нажми кнопку `Проверить текст`.
4. После получения результата включи чекбокс `Подсветить ошибки`.

После включения подсветки:

- в левом поле подсвечиваются фрагменты исходного текста, которые были изменены;
- в правом поле подсвечиваются фрагменты исправленного текста, которые появились в результате правки.

## Цвета

Ошибки в исходном тексте:

```text
background: #ffcccc
foreground: #cc0000
```

Исправления в результате:

```text
background: #ccffcc
foreground: #009900
```

Цвета задаются в `app/main.py` в методе `setup_highlight_tags`.

## Как работает алгоритм

Логика сравнения находится в:

```text
app/text_highlighter.py
```

Класс:

```python
TextHighlighter
```

Основной метод:

```python
find_differences_optimized(original, corrected)
```

Алгоритм работает в несколько этапов:

1. Разбивает исходный и исправленный текст на слова.
2. Сравнивает последовательности слов через `difflib.SequenceMatcher`.
3. Для замененных фрагментов дополнительно делает посимвольное сравнение.
4. Возвращает позиции фрагментов для подсветки в исходном и исправленном тексте.
5. Объединяет соседние или пересекающиеся подсветки одного типа.

Результат имеет такой формат:

```python
{
    "original_highlights": [(start, end, type), ...],
    "corrected_highlights": [(start, end, type), ...],
    "stats": {
        "errors": N,
        "corrections": M,
    },
}
```

## Типы изменений

Алгоритм может возвращать такие типы:

```text
replace
delete
insert
```

Это технические типы diff-операций, а не полноценная лингвистическая классификация ошибок.

Например:

```text
replace - один фрагмент заменен другим
delete  - фрагмент был удален из исходного текста
insert  - фрагмент появился в исправленном тексте
```

## Примеры

Замена символов:

```text
Исходный:     машиное обучене
Исправленный: машинное обучение
```

Пропущенная буква:

```text
Исходный:     нейроые сети
Исправленный: нейронные сети
```

Лишняя буква:

```text
Исходный:     даннных анализ
Исправленный: данных анализ
```

Пунктуация и пробелы:

```text
Исходный:     Привет мир,как дела
Исправленный: Привет, мир, как дела?
```

## Тестирование highlighter

Можно проверить модуль отдельно:

```bash
python app/text_highlighter.py
```

Скрипт выведет тестовые пары текстов и найденные позиции подсветки.

## Ограничения

Подсветка показывает различия между двумя строками, но не знает, почему модель сделала конкретное исправление.

Например, если модель изменила пунктуацию, пробел и букву рядом, diff может подсветить весь соседний фрагмент.

Также алгоритм использует `split()` для сравнения слов, поэтому сложные случаи с несколькими подряд пробелами или нестандартными переносами могут подсвечиваться приблизительно.

Эта функция нужна прежде всего для визуальной диагностики: быстро увидеть, что модель поменяла, а не для точной классификации типов ошибок.
