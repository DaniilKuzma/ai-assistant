# Agent Instructions

Project Markdown instructions are split into separate files under `rules/`.
Read the relevant files before changing related code, data generation,
evaluation, or runtime behavior.

## Rule Files

- `rules/project-guide.md` - project purpose, source map, data layout, error
  scope, runtime usage, GUI, and quick checks.
- `rules/runtime-architecture.md` - HybridCorrector action space, protected
  text, candidate/context layers, guards, recovery behavior, and artifact
  contract.
- `rules/training-and-evaluation.md` - training command, smoke/external
  evaluation commands, notebook scenario, report locations, and acceptance
  targets.
- `rules/evaluation-metrics.md` - evaluator metric definitions, V10.5
  diagnostics, and result interpretation notes.
- `rules/strict-baseline-package0.md` - package 0 baseline metrics, dataset
  distribution, taxonomy checkpoint, and acceptance criteria.
- `rules/strict-error-taxonomy.md` - strict orthography and punctuation scopes,
  quarantine/forbidden labels, and runtime contract.
