# Russian Edit Corrector

Система консервативного исправления русской орфографии и пунктуации. Проект
исправляет только локальные ошибки и не должен менять смысл, стиль, порядок
слов, время, падеж или добавлять новые смысловые слова.

## Архитектура

- обучающие примеры создаются в процессе обучения программами `RuleProgram`;
- модель на базе RuRoBERTa предсказывает прямые правки токенов и пунктуационных
  промежутков;
- при выполнении сначала применяются детерминированные правила, затем —
  консервативные правки модели;
- большие материализованные обучающие CSV-наборы не используются.

Основные компоненты находятся в `src/`, конфигурация — в `configs/config.yaml`,
тесты — в `tests/`, а подробное описание обучения — в
`docs/new_training_pipeline.md`.
